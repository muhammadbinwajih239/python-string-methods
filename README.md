# Python String Methods

This repository contains simple examples of 20 useful Python string methods.

## Methods Covered

- lower()
- upper()
- capitalize()
- title()
- strip()
- lstrip()
- rstrip()
- find()
- count()
- replace()
- startswith()
- endswith()
- split()
- join()
- isalpha()
- isdigit()
- isalnum()
- islower()
- isupper()
- isspace()

## How to Use

Open `string_methods.py` and run it with Python to see the printed results.

## Purpose

This project is for practicing Python fundamentals and understanding common string methods through simple examples.
