# Python String Methods

This repository contains simple examples of 20 useful Python string methods.

## Methods Covered

- lower()
- upper()
- capitalize()
- title()
- strip()
- lstrip()
- rstrip()
- find()
- count()
- replace()
- startswith()
- endswith()
- split()
- join()
- isalpha()
- isdigit()
- isalnum()
- islower()
- isupper()
- isspace()

## Purpose

The purpose of this project is to practice Python string methods
using simple examples and print statements.

- Python Fundamentals
- String Methods
