# Python Input Validation

This project contains four simple Python programs built to practise string methods and input validation.

## Programs

1. **Email Validation**
   - Checks a basic email format.
   - Uses strip(), count(), and find().

2. **Employee ID Validation**
   - Checks the EMP-1234 format.
   - Uses startswith(), len(), slicing, and isdigit().

3. **License Plate Validation**
   - Checks the ABC-1234 sample format.
   - Uses upper(), len(), slicing, isalpha(), and isdigit().

4. **Password Validation**
   - Checks basic password format conditions.
   - Uses len(), isalnum(), isalpha(), and isdigit().

## Python Concepts Practised

- String methods
- String indexing and slicing
- Conditional statements
- Logical operators
- User input
- Input validation

## How to Run

1. Open the project folder in VS Code.
2. Open any Python file.
3. Run the file using Python.
4. Enter the requested input and check the result.

## Note

These programs use simple practice rules. They are not complete validation systems and do not verify the existence of email addresses, official employee IDs, vehicle registrations, or password security.

## Purpose

The purpose of this project is to apply Python string concepts to simple, practical input-checking examples.
